西条酒蔵めぐり｜写真反映版

【今回の症状】
ロゴや写真が出ない場合、HTMLに写真の参照があっても、GitHub側に assets フォルダが入っていないと表示されません。このZIPには画像・動画を含む assets フォルダを入れています。

【確実な反映方法：GitHub Desktopを使う】
1. このZIPをダウンロードし、右クリック→「すべて展開」します。
2. GitHub Desktopを開き、対象リポジトリ「ud-summer」を選びます。まだPCにない場合は、File → Clone repository から https://github.com/6t7btn28g4-art/ud-summer.git をクローンします。
3. ZIPを展開したフォルダの中身をすべて選択し、GitHub Desktopが示すローカルの「ud-summer」フォルダにコピーします。同名ファイルは置き換えます。
4. ローカルフォルダの中に、index.html、map.html、compact-ui.css、corporate-simple.css、assets、audio が同じ階層にあることを確認します。assets フォルダの中には images と video があることも確認します。
5. GitHub Desktopに戻り、Summary に「写真表示を修正」と入力し、Commit to main を押してから Push origin を押します。
6. GitHubの Settings → Pages で、公開元が main / (root) であることを確認します。
7. 1〜3分待ち、Ctrl+F5で再読み込みします。

【写真が反映されたか確認する】
公開後に https://6t7btn28g4-art.github.io/ud-summer/image-check.html を開きます。サンプル写真が表示され、各項目が「OK」なら画像は公開されています。NGがある場合は、その項目名と画面を送ってください。

【重要】
- ZIPファイルそのものをGitHubへアップロードしないでください。解凍後の中身をリポジトリにコピーします。
- index.htmlだけを更新しても写真は公開されません。assetsフォルダの中身も全部必要です。
- この環境からGitHubへ直接Pushはできないため、アップロード後の実表示確認はまだです。
